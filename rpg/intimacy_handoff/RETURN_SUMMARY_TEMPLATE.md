# Шаблон возвращения сюжетных итогов из Grok

**STATUS:** TEMPLATE_ONLY. Никакого завершённого внешнего эпизода пока нет.

## Карточка эпизода
- ID / исходная глава / исходный чекпоинт:
- Где прочитана исходная история (точные файлы и версия):
- Начало: полная дата, время, место:
- Конец: полная дата, время, место:
- Какие персонажи действительно присутствовали:
- Неграфическое резюме события (что произошло и почему важно для истории):
- **Стас: решения, конкретно выбранные игроком** (по порядку, с репликами если важно):
- **Драка: собственные инициативы/слова/границы/решения**:
- Согласие и остановки: что было добровольным, что оставалось только предложением:
- Значимые последствия для доверия, близости, эмоций, возможные изменения отношений:
- Новые сообщённые факты (и кто их узнал):
- У кого **нет** этих знаний:
- Изменения инвентаря, денег, времени, обязательств, Кубка (или «нет»):
- Конфликты с предшествующей хронологией / неопределённости:
- Последняя реплика или незавершённый выбор:
- Точная точка продолжения основной RPG:
- **CONFIRMED**: действительно сыгранные факты:
- **PROPOSED / OPEN**: предложения и вопросы без результата:
- **PRIVATE**: сведения, которые не могут автоматически узнать другие:

## Как использовать
Готовый итог прислать пользователем обратно в основную беседу. Ассистент сверяет с GitHub и ранее сыгранными главами, при необходимости помечает конфликты, затем **по запросу пользователя** сохраняет неграфический канонический итог и обновляет дельта-пакет. Сексуальные подробности могут оставаться только в личном тексте пользователя и **не обязаны публиковаться** в GitHub. Не описывать новые действия Стаса без выбора игрока.


## Поля V2 — обязательно заполнять при реальном возвращении
- `scene_id` (тот же, что в HANDOFF_STATE и SCENE_PACKET):
- `source_commit` / текущая версия исходного контекста:
- `report_id` (уникальный ID отчёта, для защиты от двойного импорта):
- `terminal_reason` (почему сцена естественно завершилась, а не оборвалась):
- `return_offered` (да/нет, точная формулировка предложения):
- `return_accepted` (да/нет, подтверждение игрока):
- Сведения о реальных свидетелях и отдельно **лишь возможных** свидетелях:
- Сведения, ставшие известными каждому персонажу, и конкретный способ получения:
- Оставшиеся незавершённые выборы / действия (или «нет»):
- Состояние импорта: NOT_IMPORTED / RECONCILED / CONFLICT (Grok не может самостоятельно объявить RECONCILED):

Не добавлять PROPOSED-события к CONFIRMED. При повторном `report_id` дельту не применять. Не публиковать графическое содержание. Для сцены без Стаса записать «его решений нет», а не выдумывать выбор за него.
