## Извлечённая переписка

- [Читаемый текст](archive/conversation_readable.txt): удалена оболочка, сохранены порядок, таблицы и варианты с номерами.
- [Текст с исходным содержимым сообщений](archive/conversation.txt): дополнительно сохранён встроенный текст GenUI/динамических данных для проверки очистки.
- `archive/messages.jsonl` — 839 сообщений с постоянными M-идентификаторами; `messages_readable.jsonl` и `evidence.jsonl` — производные для поиска.

Числовых пропусков нет, но есть ограничения **самого HTML**: M2 обрывается, M36 — только `skipped_mainline`; первый игровой кадр уже в дороге, предшествующие домашние сцены не представлены. Они не дополнены выдумкой. Подробности — в аудите.

Продолжение регулирует [AGENTS.md](AGENTS.md): перед ходом читать актуальное краткое сохранение, сверять канон, после каждого хода обновлять изменившиеся данные. Новые ходы — [журнал кампании](rpg/campaign_log.md). Никакого следующего игрового выбора в ходе восстановления не сделано.

Скрипты `extract_archive.py`, `index_archive.py`, `prepare_batches.py`, `finalize_memory.py` воспроизводят извлечение/индекс/сборку; вспомогательные `read_*.py`, `inspect_evidence.py`, `batch_packet.py` позволяют читать адресно. **После продолжения игры не пересобирать память старым скриптом:** производные текущего состояния могут быть перезаписаны архивными данными.
